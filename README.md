# 🏥 Healthcare Analytics Dashboard (Power BI)

An interactive Healthcare Dashboard built in Power BI to analyze hospital and patient-related data, providing insights into billing, admissions, demographics, and medical conditions. This dashboard is designed to help healthcare providers and decision-makers optimize resources, improve patient care, and track financial performance.

📌 Overview

The dashboard covers:

-Total Billing Amount: $103.96M

-Patient Admissions by Year & Type

-Length of Stay Analysis (82,897 months)

-Patient Demographics: Gender, Blood Type, Age Groups

Medical Conditions Distribution

Billing by Hospitals & Insurance Providers

📊 Features

-Admissions Trend Analysis – Visualizes hospital admissions across multiple years.

-Length of Stay Insights – Tracks patient stays in hospitals for efficient resource allocation.

-Demographics Breakdown – Gender distribution, blood types, and age-based insights.

-Medical Condition Analysis – Identifies the most common health conditions among patients.

-Billing & Insurance – Shows total billing, hospital-wise billing, and insurance coverage patterns.
